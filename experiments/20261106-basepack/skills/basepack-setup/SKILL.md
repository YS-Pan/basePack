# basePack installation and upgrade

Choose the capabilities and target project with the user. Inspect the existing interpreter, installation, project configuration and active facilities before changing them; reuse working infrastructure. Read the relevant sources together:

- [Installation and capability choices](https://github.com/YS-Pan/basePack/blob/main/README.md#install-the-lightweight-client)
- [Project setup, credentials, backup restoration and skill discovery](https://github.com/YS-Pan/basePack/blob/main/experiments/20261106-basepack/docs/setup-project.md)
- [Administrator facility preparation](https://github.com/YS-Pan/basePack/blob/main/experiments/20261106-basepack/docs/administrator.md)
- [Configuration, upgrade and recovery dependencies](https://github.com/YS-Pan/basePack/blob/main/experiments/20261106-basepack/docs/project-config-maintenance.md)

Use the matching release documentation. Follow the selected capability's instructions to choose an interpreter and installation location, prepare only its facilities, bind the project and restore its own credentials or backup where needed. For an upgrade preserve the applicable recovery set and follow the version-specific migration before switching clients. Verify the actual interpreter, package version, project binding, facilities and shortest enabled flow; check host skill discovery separately. Report observed results, unresolved prerequisites and original errors. For ordinary memory use or maintenance, use the installed memory skill located by `memory guide`.
