# 项目术语

本表解释开发材料中的特有概念；已交付接口见 [记忆模块](system/modules/memory.md) 与 [资源模块](system/modules/resources.md)，记忆阶段结果与未验证范围见 [记忆进度](tasks/20261106-memory-system/progress.md)。

| 术语 | 在本项目中的含义与边界 |
| --- | --- |
| 性能（agent 与团队） | 完成任务的能力水平与成果质量：能否处理单个 agent 原本无法完成的材料规模或复杂任务，以及已有可做任务的正确性、完整性和判断质量是否提升。允许增加用量以换取更好的性能；用量和耗时作为代价单独记录，节省用量不作为 agent 协作的成功条件 |
| 产品源码与项目实例 | 产品源码维护可复用工具；项目实例是工具服务的具体项目，保存该项目自己的配置、知识和运行数据 |
| 来源原件与来源记录 | 原件是文件、图片或聊天等材料；来源记录保存其身份、位置和版本等定位信息，登记不代表已经理解 |
| 检索成员与语义节点 | member 表示文件摘要、实际章节摘要、智能原文块或图片，同时可检索并作为图节点；额外语义节点表达实体、决定、条件等知识，以成员为依据。成员数量不代表建图质量 |
| 图关系 | 节点之间有依据的语义关系，可包含条件；同目录或字面相似可作为寻找关系的线索 |
| 语义知识与派生索引 | agent 判断形成的知识需保留依据与更正；文字、向量等索引服务检索，重建索引不等于重新验证语义判断 |
| 共享资产与项目记忆 | 环境、模型权重和机器资源设施可以显式复用；来源、知识和任务状态属于各自项目 |
| 检索 worker | 接受检索目标与预算、按需阅读和评分并返回证据的执行角色；准备任务包与实际派发是不同动作 |
| 常驻信息与按需信息 | 按 [纲领中的常驻信息要求](project-charter.md#记忆系统具体内容) 区分；文档有路径不代表其内容已经交付给工作 agent |

模型等级以 tier1、tier2、tier3、tier4 为稳定代称；具体映射由项目配置维护，用户定义的角色要求以 [项目纲领](project-charter.md#术语) 为准。
