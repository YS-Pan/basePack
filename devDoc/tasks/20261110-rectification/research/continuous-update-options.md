# 持续追新的简化方案比较

2026-11-10，按用户要求分析现有实现并查阅成熟实现。本文保留当时四种方案的比较，未实现新机制。用户随后明确查询与维护独立、自动维护不得延长业务任务，故原推荐已被[计划第1节的目标架构](../plan.md#1-查询自动维护与手动维护的目标架构)替代；查询不触发维护。

## 当前方案的实质

已有prepare交付新/旧原件与expected（`memory/store.py:128–185`）；apply核来源revision和目标/依据知识版本、事务接受并保留source_version（`:256–326`、`:446`）；embed按输入版本复用及写入（`memory/vectors.py:14–68`）。用户编辑可继续，变化经现有changes/pending发现。已经具备追新的主要数据合同，复杂度主要来自每次变更触发多少次读取、协调和重新接受。

可以分别选择三层：**触发**决定什么时候工作；**合并**决定是否跳过中间保存版本；**接受**决定旧草稿如何避免覆盖新知识。下面四种使用方式可以组合，不必把它们建设成四套系统。

| 方案 | 做法 | 优点 | 代价与适用范围 |
| --- | --- | --- | --- |
| ①任务/查询按需更新 | brief或任务开始发现变化，优先维护本任务相关来源；已知位置也可直接读原件 | 新设施最少，冷资料不反复消耗agent | 首次使用变化资料可能多等一小批；无任务时不自动理解新资料，不能独自替代全范围扩库/未知前提维护 |
| ②任务内合并最新候选 | 在每批边界汇总变化，同一路径多次保存只取当前最新候选；tier1一次阅读同时分块、摘要和建边，tier2只整合必要小批 | 保持扩库期间追新，少读中间版本；复用现有版本与事务，无常驻服务 | 热源可能暂时待核；跨来源关系仍须共读两端，不能让“最后写入”绕过expected |
| ③后台监听并合并 | 用文件监听器聚合变化，宿主在可用时派worker做语义维护 | 变化发现及时，用户操作更少 | 增加监听进程、任务驱动和跨会话待办；监听器只发现文件变化，本身不会理解或建图，仍需宿主订阅agent，不能假定已有LLM API |
| ④不可变版本先建图再接受 | 先捕获一份来源快照，允许阅读完成，再按版本条件接受适用结果；旧版本作为历史保留 | 阅读不被每次保存打断，适合很大且频繁变化的来源 | 当前apply在接受时核现行原件，source_version也在这一步才产生；完整实现还需候选图、发布关联及跨版本关系处理，改动和状态最多，仍需区分历史与当前 |

## 原推荐与最新取舍

原先推荐①作为入口、②作为执行方式。最新选定为：任务生命周期独立驱动自动维护，复用②的来源合并与既有版本条件；查询始终只读已发布知识和对应依据快照。候选内容及向量准备完毕后小批原子发布，业务结束即停止新批和未发布工作，查询不等待。积压较多只提醒用户，手动维护由用户明确发起。

仍采用的机制是任务内按路径合并、同来源串行整合、跨来源适度并行，以及冲突后重新共读受影响依据。变化发现只在维护侧执行；原件变化记录待办，不立刻隐藏最后发布态。旧快照以其实际版本回源，不能冒充当前原件；已知错误或显式退役仍排除。具体生命周期、发布边界与完成条件只在计划维护。

不选择③的常驻监听与无人值守维护。借用④的候选准备/发布隔离，但复用现有数据库、source_version和批次，不建设完整的多代查询库或全局版本平台。

## 查阅到的成熟机制

- [LlamaIndex文档管理](https://developers.llamaindex.ai/python/framework/module_guides/indexing/document_management/)以稳定doc ID刷新变化文档，未变化文档可跳过；借鉴来源粒度及增量刷新，不引入其整套框架。
- [watchfiles](https://watchfiles.helpmanual.io/api/watch/)用debounce/step聚合文件变化；它解决变化事件合并，不负责语义更新。方案②可在现有任务批次边界达到类似合并效果，无需先安装监听器。
- [Qdrant条件更新](https://qdrant.tech/documentation/manage-data/points/#conditional-updates)展示按应用版本条件避免旧写入覆盖新结果；本项目已有expected，应复用该原则，不能将幂等upsert误当成旧草稿可覆盖新版本的授权。

上述机制各解决一层问题，不能直接替代本项目的多材料共读、语义关系及原文追溯。当前`changes`的库外旧状态到无条件stale写入之间仍需计划中的交错回归；合并事件本身不能修复该并发风险。
