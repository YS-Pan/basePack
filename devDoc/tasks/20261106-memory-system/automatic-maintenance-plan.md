## 调用与发布边界

- AGENTS只放立即行为；本机instructions保存Python、显式配置及安装材料位置；随包memory skill/英文角色模板维护细节。普通init和memory init共用托管块刷新，保留块外字节，升级不重置UUID、凭据或知识。
- 默认发现仍覆盖全项目Git清单、显式纳入、已登记来源、历史待核和归属聊天，不按当前业务文件收窄。回执固定候选与聊天截点；每批prepare读其当时版本，不宣称全项目原子冻结。新增材料留下一轮，不在收尾追赶当前聊天。
- 普通维护按业务生命周期停止；显式“维护记忆”本身是交付，须处理授权范围或报告实际阻塞，不能以若干优先批或剩余数字结案。
- 取得owner者统一负责预检、协调者、reader及发布。结束stop自有control、取消自有后代，发布已结束后release。已获准提交不等于已完成；结果不明保留owner与原错。异常恢复核旧任务已结束及发布结果后显式执行，不按锁年龄抢占。
- 来源和知识版本、chunk逐字一致、相关依据与向量identity检查继续执行。父项合法性不增加同源、固定三级、范围包含或全图无环等未定规则。依赖写guard解决快照隔离写偏斜，不改变未变依赖的逻辑版本或change历史。
- WebSocket消息采用有限2,162,688字节上限，按实际序列化分包；这不是调高HTTP /sql服务配置。单条操作超限明确失败，不篡改语义块；提交响应丢失用同事务标记确认，未确认不得盲重放。32MiB HTTP提案不作为已部署设置。
- 反馈保存在记忆库并随原生导出恢复，不作为业务原件自摄入。普通报告不直接成为事实，也不自动启动审计；旧报告不得覆盖新版，未决/失败/冲突如实保留。
- 只有用户明确表达记忆系统审计意图才启动手动审计；讨论该词、普通维护或问题报告不触发。只读审计可报告问题，修复仍取得owner。

## 验证口径与已知限制

开发验收覆盖新/旧项目入口刷新及块外字节、真实普通任务默认启动/派工/停止、双进程互斥、父/依据版本冲突、多消息原子性、单条超限、提交结果不明、反馈并发/漏检/旧版本与原生恢复、B/F失效和重复入队。完整回归及独立wheel实测的具体命令、数据库和跳过条件见实施结果；开发测试不成为每批知识的事后审计门槛。

同档位小样本中，两作者均读1,163字符的五份材料；细/粗完整输出6,726/7,955字符，不能证明粗层更省。无变化样例baseline/candidate为3/0语义候选，但候选单次预检更慢且未计处置建立成本。粗层输出还出现不相邻原句拼接成连续依据的问题。保留这些反例，不以机械通过、节点数或候选减少替代质量与总成本结论；精确协议、实际输出和未可得用量见实施原证。

隔离验证使用SurrealDB4.0.0内存引擎；SurrealKV磁盘、自定义WebSocket服务端限额和长期负载未验。Windows曾有一次owner.json替换WinError5，实际占用者未知；保留错误和观察条件，不加盲目重试。真实使用的问题继续进入本专项进度和反馈。

目录清理不凭tmp/artifacts名字删除原件：先核配置、受管来源、source_version/basis与活动使用，独有原证先选留，按精确清单操作；不迁库、不改凭据，不删除数据库WAL/vlog。分别记录删除量、选留量、保留例外及功能检查，空间减少不当作AI提速。正式客户端仅本项目接入新独立环境，其它项目共用的0.9.1环境及共享模型服务保持原状态。
