## 实现与交付边界

- SurrealDB 是唯一知识基座；member 复用为文件/章节/块/图片表示与图节点，语义边独立存条件与依据。中文全文、原生精确向量与排名融合直接查各层，未预建多后端、ANN 或跨库同步。
- 智能边界、摘要、视觉理解和语义关系由实际宿主订阅 agent 同读产生；结构提示不冒充语义分块。已接受表示、更正及旧依据持久保存，恢复索引无需重新总结。
- 来源版本、知识版本、表示输入版本和 embedding_identity 各有职责；旧草稿不覆盖新更正，原文修改失效依赖祖先及相关边，未变块可复用。
- brief 直接交付必保信息、短地图、相关线索和缺口，合并检查已登记原件及 source_scope。普通启动用元数据；深维护显式核 hash。新增只发现不理解，待核内容不作当前事实。
- 普通 init 不建库；memory init 绑定项目 UUID 并激活随包 skill。项目配置、原件/必要 assets、知识与历史属于对应项目，通用 exe 和模型可以共用。Git 忽略及缓存均不能代替备份。
