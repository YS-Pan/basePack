## devDoc 自用

本项目 source_scope 显式限定三份资料：项目纲领、文档维护约定和记忆计划。实际 reader 共读后生成智能块、文件/章节摘要与跨材料关系；原件仍在原业务路径。该范围不代表整个 devDoc 已覆盖，也不继承旧项目知识。

实际 reader 的 [首建与验证回执](../../../artifacts/runs/20261109-memsys-p5/devdoc/devdoc-initial-result.json) 记录三份原件的同读边界、摘要和关系依据；prepare 后计划末段变化时重核了该段及实际版本。brief 实收三条必保留原文，关系展开可回两端依据，三条严格 read 回到所记原文范围，包括更新后的计划末段；deep changes、pending、覆盖缺口及待编码均为空。一次宽泛中文查询无命中，收据如实保留，未把词法分数当作语义评分。

本项目已做原生 export，选留集合还包含对应配置和这三份原件；它是本轮恢复原证，长期备份策略仍由业务接入确定。
