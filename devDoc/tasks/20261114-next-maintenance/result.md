# 0.14.0 私有上下文与记忆标记交付

2026-11-14（北京时间）。按[计划](plan.md)实施，源码、普通 wheel 与本项目稳定客户端为 `0.14.0`，完成版本使用普通数字命名。旧 `v0.13.0.dev1` 及其恢复资料保持历史身份；后续按用户明确授权推送源码并发布[常规版v0.14.0](https://github.com/YS-Pan/basePack/releases/tag/v0.14.0)，具体附件与验证见[GitHub发行](#github发行)。

## 结果

- 根 `private/` 已建立独立本机 Git，外层 `/private/` 整体忽略，不使用 submodule/worktree，不设置 remote。内层有自身忽略和本机索引，按真实内容增长目录；公共文档只保留可公开且自足的结论及可选中性引用。
- 限定清点了 Git 清单及相关开发原稿/来源索引，未确认需迁入的机密业务原件，实际迁移映射为 `[]`。没有为填充私有区而搬一般开发讨论，也没有审计外部项目、受管聊天原件或全部 Git 历史；不据此作无泄漏结论。
- 默认发现使用外层项目清单加内层 Git 的已跟踪/未忽略文件，尊重私有忽略；无私有目录正常，显式 scope 不额外加入私有新来源。两仓仍服务同一项目 UUID/数据库。
- 只增加一个逻辑布尔标记 `private`，在来源、快照及知识写入处按来源和固定版本依据/端点计算；公私混合整条私有。prepare、read、brief、搜索与交接保留标记。仅状态更新保留原标记；原生 schema 的历史保留事件继续携带它。
- file-structure 新增[私有上下文模式](../../../skills/file-structure/references/private-context.md)，与公共单套 devDoc、实验路线组合；受管记忆副本和工作包保留原有受忽略位置。通用技能不继承本项目姓名/邮箱等具体公开授权。
- 项目配置 schema 2、成员身份版本 2、UUID、端点、凭据与向量身份保持。只升级本项目稳定客户端；共享 embedding 服务仍为 0.13.0.dev1，其它项目未代迁。没有新建公开导出平台。

## 验证

源码从唯一 active 路线导入。全套首轮 **629 passed、5 failed**：四项因本次验证传错机器配置路径，另一个 Windows ACL 测试需要正常用户上下文；改用项目实际配置及正常权限后，这 **5 项全部通过**。合计覆盖 **634 项，无最终跳过或未解决失败**。新隐私回归 12 项、默认发现回归 14 项另有定向通过依据。

普通 wheel 在源码外安装，实际从该环境 site-packages 导入，58 个包文件与 wheel 和源码逐字节一致。真实共享 embedding 下完成独立私有仓库发现、内层忽略、显式范围、公私混合传播、brief/read/history/vector 返回标记，以及移开私有原件后已发布快照回读；使用的是明确的合成资料，不冒充实际机密资料迁移。

本项目补标后，从升级前原生导出恢复到独立测试 namespace/database，按记录身份比较 source 1,308、source_version 1,677、member 6,513、node 80、semantic 227、knowledge_version 3,088、change 11,526、access_state 33、delivery 5、feedback 6，排除新增标记后十表全部一致，当前记录的全文/向量完整指纹一致。原先按列表行序比较的校验失败已由逐 ID 对照排除，原库未回退或丢弃状态。

原库当前来源/快照/知识共 **9,805 条**可确认记录已补标，均为既有非 private 路径；没有新增私有原件被冒充为实际迁移。保留的旧副本仍有 **495 处**无法从现有版本依据确认（知识归档29、单条 previous240、分组 previous226），保持缺标，不宣称这些内容可公开。它们是历史副本计数，不是495份独立业务原件。三条 mandatory 保留并返回标记。

临时路径/归档检查用隔离夹具验证了普通文件与 gitlink 拒绝、移除旧条目放行、干净归档通过及含 private 路径归档拒绝；实际提交/发行清单完成相关检查后撤除检查器和调用，不安装永久 hook 或 CI 门禁。
