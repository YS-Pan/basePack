# 0.19 统一记忆图

## 旧库迁移与回退演练

0.19 将结构、原证和业务关系存入同一张原生关系表。关系和知识的确切版本可独立回读。按需检索默认走有界多跳，worker 可按原证调整起点、方向及适用条件。宿主按实际交付的知识版本记账。

schema 3 项目先保存完整恢复集合，再按[项目升级流程](../../../experiments/20261106-basepack/docs/setup-project.md#升级到-019-的统一图)运行离线转换。缺版本钉或未经确认的旧关系保留在历史入口，并注明原因。旧记录的隐私未知时会从公开检索排除。转换结果须在独立空库导入并核对，回退应先保全新库已接受的发布和交付。

已在 SurrealDB 4.0.0 上验证正常发布、失败事务回滚、精确原证、历史回读和空库恢复。带 8,682 个现行成员的合成规模测试另行核实原生导出与独立恢复一致。

安装、功能入口和恢复步骤分别见[根 README](../../../README.md)、[记忆使用说明](../../../experiments/20261106-basepack/docs/memory.md)和[恢复集合](../../../experiments/20261106-basepack/docs/memory.md#备份与恢复)。
