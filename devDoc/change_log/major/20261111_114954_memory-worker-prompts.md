# 英文维护 prompt CLI 与全项目默认维护

0.9.0 将 coordinator/reader 英文 prompt 随 wheel 分发，subagent 执行 `memory prompt` 获取按项目路径、角色和 tier 渲染的任务说明；宿主实际设置模型。渲染不连接数据库/模型或写状态，角色与计算档位独立。

默认维护从项目 Git 清单加显式包含项发现来源，接续既有来源、历史待核和有归属依据的聊天/附件。main 普通调用沿全项目默认；协调者负责持续接批、共读、发布和真实 ID/范围覆盖验收，特殊情况仍可临时英文派工。没有新增模型 API、后台调度平台或数据库 schema。

最终普通 wheel 源码外 395 passed/0 skipped，受影响源码 47 passed，42 包文件逐字节一致；真实订阅团队连续发布、规范捕获定位和范围补漏后独立预检零语义候选。稳定客户端已普通升级 0.9.0，本项目新 shell 入口及既有知识保留验证通过。正常后台维护使 426 待核降到 397，余项未清零。实际条件、负夹具与余项见[结果](../../tasks/20261111-memory-worker-prompts/result.md)。
