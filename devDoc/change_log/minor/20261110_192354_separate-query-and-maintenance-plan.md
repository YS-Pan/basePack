# 查询与维护解耦的架构计划

按用户最新要求重定整改计划第1项：查询只读已发布知识和对应依据快照；自动维护随业务任务并行开始，业务结束即停止接新批、取消未发布工作，不等待维护完成。积压较多只提醒，用户明确发起后才启动独立手动维护。

设计复用现有数据库、版本条件和批次，候选内容与向量准备好后短事务发布；来源变化不撤下上次发布态，显式退役/更正仍排除。新增两张逻辑框图，更新总进度及研究材料，原“查询按需触发更新”推荐标记为已替代。

本次只改计划文档，未修改产品代码、未运行维护。检查差异、相关本地链接、UTF-8及两张Mermaid定义；功能与停止响应的验证列为后续实施完成条件。详见[整改计划](../../tasks/20261110-rectification/plan.md#1-查询自动维护与手动维护的目标架构)。
