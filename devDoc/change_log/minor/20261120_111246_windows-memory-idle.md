# Windows 项目记忆库空闲停机

固定端口的 Windows 项目库登记可选 `--idle-seconds`。受管操作结束后计时，按需唤醒复用原任务。空闲时通过定向信号正常关库，在途操作和未明发布保留实例。冷库的自动维护预检在使用 control 和申领所有权前给出限定启动命令。
