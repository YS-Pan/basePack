# 调查 SQL 请求上限并给出本机容量建议

2026-11-11（北京时间）。

核对 SurrealDB v4.0.0、HTTP 限额配置化历史及请求限制实现，明确 0 不表示无限、无效字符串会回退默认值，未找到 1 MiB 原始数值论证或官方稳定最大值。
