# 扩充项目术语与常见叫法

复核近期 Codex 项目对话和相关业务对话，按现行文档确认术语边界。[项目术语](../../terminology.md)新增「首选词／其他叫法或查找线索／含义与边界」结构，并说明如何按原称查词、引用原话和补充别名。

补充了聊天采集与知识发布、维护读者与检索 worker、交付与访问投影、AI 档位、项目库与 Windows 托管等反复出现的用词。比如「入库」按实际进展明确为原件采集、来源登记或知识发布，Luna 和 Terra 按语境区分模型与角色。把派工与唤回、Codex 聊天归属与记忆库身份也纳入查词范围。

批量聊天覆盖核对遇到已知 SQLite 权限错误，改用 Codex 对话读取补证。验证包括 UTF-8、仓库内链接与锚点、常见叫法查找和 Git 差异检查。
