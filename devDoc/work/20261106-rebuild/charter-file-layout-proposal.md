# 文件结构建议：纲领建议稿

以下正文供用户填入纲领的“文件结构建议”空节；本文件不会自动写回纲领。

文件结构建议作为独立工具，以 skill 的形式提供，帮助人和 ai agent 选择、建立和维护适合项目的文件组织方式。它可以独立使用，也可以供记忆系统参考。

1. 提供多种可选择、可组合的推荐结构。初版包括当前项目的 devDoc 开发文档结构，以及旧项目未完成的实验分包结构：将每种独立尝试的代码、依赖、资料、状态和结果组织为相应的实验工程单元。
2. 根据项目的类型、规模、阶段和已有组织方式选择或调整，保持结构与说明简洁，方便理解、读取和维护。
3. 未来可以继续增加其它推荐文件结构。
