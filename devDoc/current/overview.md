# 当前实现概览

本仓库已提供两项可独立使用的 skill：[project-layouts](../../skills/project-layouts/SKILL.md) 用于推荐或整理开发文档和实验工程布局；[agent-team](../../skills/agent-team/SKILL.md) 按任务规模组织主 agent、协调 agent 与执行 agent，使用宿主已有的订阅 subagent 能力。
